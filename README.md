## Prerequisites

To use Good First Issue, you will need the following:

- **Node.js 8.0.0 or above**
  - Download from the official website: https://nodejs.org/en/download/
  - Alternatively, use a version manager such as nvm (available for macOS, Linux, and WSL).

- **npm 5.0.0 or above**
  - npm comes bundled with Node.js.
  - To update npm globally, run:

```bash
npm i -g npm
